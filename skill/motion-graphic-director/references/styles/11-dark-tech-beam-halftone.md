# Style 11: Dark Tech Beam, Optic Bloom & Halftone Matrix (Supabase / Vercel Inspired)

Use this direction for developer platforms, AI builders, analytics/database SaaS, and technical flagship promos that demand prestige dark precision, high legibility, and spacious ASMR pacing.

## Visual Signature & Surface Physics

1. **Charcoal-Obsidian Ground + Diagonal Light Beams:**
   - Matte dark charcoal/obsidian canvas (`#080808` to `#181818`) illuminated by subtle diagonal brand-colored light beams (`#182828` / `#3ECF8E` emerald, or brand primary at low luminance) that breathe gently behind typography.
   - Layer sparse floating syntax brackets, tabular data planes, or a clean wireframe globe (`opacity: 0.14–0.32`) at blurred depth without crowding focal reading zones.
2. **Optic Rack-Focus Bloom & 1px Crisp Surfaces:**
   - Reveal key UI cards, deployment badges, and pill CTAs (`Visit ↗`) through smooth optic blur-to-sharp transitions with controlled soft rim bloom (`max 1–2` glowing targets per frame).
   - Keep dark cards razor-sharp (`#141416`, `1px solid rgba(255,255,255,0.12)`) with high-contrast white headlines and single-hue emerald/brand accents.
3. **Typography & Score Proof Discipline:**
   - Pair tight geometric display sans (`Build in a weekend`, `Start your project`) with clean monospace (`IBM Plex Mono` / `JetBrains Mono`) for real queries, deployment slugs, and radial score proofs (`rollingNumber` `16 -> 90 -> 96`).
   - Animate key verb emphasis with crisp sweeping highlight blocks (`scaleX` wipe behind word) or luminous curved light ribbons framing centered statements.

## Signature Choreography Moves

1. **Prompt-to-Code Halftone Matrix (`halftoneWaveCell`):**
   - On prompt submit click, sweep an expanding/receding glowing halftone dot wave across the center stage, dissolving the natural-language prompt cleanly into structured SQL/code output with a live `Run` button.
2. **Cursor-Tethered Macro UI Follow (`tetheredCameraFollow`):**
   - Zoom into real multi-step app forms (`1.8x–2.2x`: Table Editor -> Create Table -> Type dropdown -> Toggle -> Save) and glide the camera continuously tethered to the cursor trajectory so small UI fields stay crisp in a single uninterrupted shot.
3. **Multi-Cursor Named Collaboration (`evalMultiCursors`):**
   - Communicate live teamwork or multi-agent execution visually by animating `3–4` color-coded named pointers (`Alan`, `Jonny`, `Copple`, `Terry`) editing rows, selecting queries, and tapping channels simultaneously around a centered headline and rotating wireframe globe.
4. **Optic Score Ring & Blur-to-Sharp CTA:**
   - Animate circular performance rings smoothly via `rollingNumber`, and close with a sweeping highlight block over the final CTA phrase before settling onto the centered brand mark over quiet diagonal beams.
