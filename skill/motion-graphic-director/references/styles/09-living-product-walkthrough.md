# Style 09: Living Product Walkthrough & Visual Explain (Sleeko / ChatGPT HusniXD Inspired)

Use this direction for real product demos, AI workflow showcases, and guided tutorials where viewers understand the product by **watching real interactions happen** rather than reading paragraphs.

## Visual Signature & Surface Physics

1. **Clean Daylight Interactive Canvas:**
   - Ultra-clean white (`#FFFFFF` / `#F8FAFC`) or soft lavender-edged white (`#F6F4FF` with gentle purple corner aura) keeping focus strictly on live UI mechanics.
   - Optional **Persistent Bottom Chapter Rail** (`Intro -> Problem -> Use Case -> CTA` with a moving progress beam) when demonstrating a multi-step product story (`30–45s`).
2. **Micro-Copy + Visual Proof Pairing:**
   - Pair `2–5` word bridge titles (`"Just ask"`, `"Not only that"`, `"New product?"`) directly with authentic live UI moments. Never leave walls of static text without cursor or component reaction.

## Signature Choreography Moves

1. **Drag-and-Drop With Breathing Rim Glow:**
   - Curved hand/pointer drags a thumbnail (`PNG`/`WebP` photo) straight toward the prompt bar -> the input container widens smoothly and lights up with a breathing blue/violet rim (`pulseGlow`) -> photo snaps in (`squashStretch`) -> cursor taps Send.
2. **Macro Sidebar & Structured Output Sweeps:**
   - Pan laterally across long AI outputs into structured comparison tables, then zoom diagonally into left sidebar items (`New chat`) on hover before pulling back to a fresh canvas.
3. **Morphing Status Capsule -> Result Transformation:**
   - Replace dead loading spinners with a breathing grey status pill (`Analyzing -> Creating Image`) that morphs cleanly (`morphBox`) into the before/after visual reveal.
4. **Live Voice Orb & Real-World Bridge:**
   - Flip briefly to a dark canvas with a gently breathing sky-cloud orb during live voice-mode moments, or embed clean Tier 3 real-hand/QR photography where physical context helps.

## Benchmarks & Pacing

- **Measured References:**
  - `Sleeko / HowDo` (`44.4s`): **`78.0%` calm** / `22.0%` transitions, `dyn_p95_p10_db: 20.6 dB` (paired with concise micro-VO).
  - `ChatGPT HusniXD` (`45.0s`): **`78.8%` calm** / `21.2%` transitions (music + crisp UI SFX, voice heard only inside live AI demo beat).
- **Audio Match:** Warm upbeat lo-fi/synth groove + soft ASMR drag/drop/click SFX; always cap stereo master at `peak <= 0.92` (`ChatGPT` raw ref stayed clean at `0.847`, whereas noisy cuts must be controlled).
